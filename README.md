# 🍽️ Restaurant Rating Prediction App

A machine learning-powered web application that predicts restaurant ratings based on key attributes like location, cuisine, cost, and more. Built using **Python**, **scikit-learn**, and **Streamlit**, this project aims to provide quick insights into how various factors influence a restaurant’s rating.

🔗 **Live App**: [Try it here](https://restaurant-rating-prediction-app-havsyyu8hydddttujamutd.streamlit.app)

---

## 🚀 Features

- Predict restaurant ratings using ML models
- Clean and interactive Streamlit interface
- Real-world dataset from the food & hospitality domain
- Fully deployed and accessible on the web

---

## 🧠 Tech Stack

- **Frontend**: Streamlit
- **Backend**: Python
- **ML Models**: Scikit-learn (Linear Regression, Decision Trees, etc.)
- **Data Handling**: Pandas, NumPy
- **Visualization**: Matplotlib, Seaborn
